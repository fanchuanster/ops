# What the converter needs — all of it.
#
# This was two files until 2026-08-26: a service list, and a superset
# that added PaddleOCR for the CLI. The split existed entirely because
# the OCR engine and its models were the better part of a gigabyte and
# the deployed service did not run them. There is no OCR engine any
# more (reading a scan is Adobe's Export PDF, called from the web
# application), so there is nothing left to split.
#
# Nothing here needs a system library. That is not an accident and is
# worth keeping: WeasyPrint pulled in Pango, Cairo and a CJK font set,
# and rendering a DOCX pulled in LibreOffice. Both are gone with the
# generated PDF (CLAUDE.md section 11), which is what turned the image
# back into plain `python:slim`.

# PDF parsing: page classification, text extraction, the outline. Ships
# its own MuPDF, so no poppler and no system libraries.

# The editable master.

# Pulled in by several of the below regardless.

# plain HTTP; no provider SDK is needed for one endpoint.

# Reads XAI_API_KEY from the repo-root .env for local CLI runs. In a
# container the environment is set directly and no .env exists.

# The reading edition, and the only format generated anywhere.
